优先级为已知规则编号、已知类型、告警中心兜底。例如历史离线数据中 `R-CMD-01` 即使类型误填为张力或供电异常，也归指令日志。

## 计数与操作口径

- 数据源是 `API.alarms()` 的事件列表，计数覆盖全部网箱；悬停角标显示完整数字和“全部网箱”。
- `alarm_status !== 'recovered'` 且非 `event_origin=preset_demo` 才计业务红点；不按颜色、是否阅读、人工确认或人工处置过滤。2026-10-29用户要求定位实际异常，明确排除启动预置示例，保留在告警中心并标“预置演示”。
- 每个事件只增加一个页面计数。板块计数从二级页面计数相加，不再维护另一套板块类型映射。
- 二级导航和页面目录读同一个 `pageDots`；点击页面不改变告警状态。解除后随 API 轮询更新消失。
- 1–99 显示整数，超过 99 显示 99+；完整数字保留在 title 中，求和不截断。
- 告警中心显示每条事件的处置入口名称。处置按钮先校验告警所属网箱、切到所属网箱，再按同一映射导航；归属不明仍拦截，不从处置中心直接下发设备命令。
- 结构规则页显示相同的处置入口。结构历史曲线的 `hits` 是历史规则命中，未注册为事件时不额外算成未解除告警。

本表确定页面归属，不补造告警的网箱归属，也不改变告警阈值或生成条件。

## 2026-10-29 告警定位补齐

`/api/struct`按当前有效末点登记锚链张力（80%提示/95%告警）与倾角（5°提示/15°告警）的`struct_monitor`事件，记录真实来源标记（当前为simulated）、cage_id/site_id、chain_id或姿态字段、触发值/阈值/快照。重复轮询不重复登记，升级保留同事件ID，低于提示线才恢复；缺数/离线不冒充恢复，另一网箱正常不解除本箱事件。此处“实际异常”指接口读数确已越限，不把模拟器称为现场传感器。

监测详情默认增加“未解除告警”分屏，列表与角标完全同源且覆盖全部网箱。选择事件查看触发快照，点击“定位异常测点”切至所属网箱与锚链/姿态/网衣分屏；有chain_id时选中该链趋势。未知归属禁用定位并解释原因。告警中心/处置入口传递事件ID，可直接打开正确对象。历史窗口命中仍与当前事件分开，不将每个历史越限点刷成新告警。
