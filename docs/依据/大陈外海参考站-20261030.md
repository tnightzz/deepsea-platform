# 大陈外海场景与DCN参考站依据

2026-10-30，用户确认以“大陈外海＋DCN参考数据”替换二号网箱的小麦岛节点。`site_03`、`cage_02`编号不变。

## 为什么选大陈

大陈海域有公开的深远海养殖项目依据。浙江政府公开的《创新型深远海智能化养殖平台建设项目（一期）》环境影响报告（SIO2022-04，2022-08）列明项目位于大陈镇竹屿岛西南侧海域，采用桁架结构，报告正文第7页说明养殖区水深达20m。此资料用于说明当地存在匹配的养殖场景，**不代表本队网箱已在该项目落地，也不证明DCN台站本身是离岸浮标**。[政府公开报告](https://zjjcmspublic.oss-cn-hangzhou-zwynet-d01-a.internet.cloud.zj.gov.cn/jcms_files/jcms1/web2432/site/attach/0/5ccbb9d27aa049d8abbbc89996d2b17b.pdf)

八部门意见对桁架类网箱及养殖平台提出原则上布设于低潮位水深不小于20m或离岸10km以上海域的空间要求；这是养殖布设口径，不应与海洋学意义的深海混同。[八部门意见原文](https://app.www.gov.cn/govdata/gov/202306/13/504106/article.html)

## 海况、水温数据

- 来源：国家海洋科学数据中心“中国台站观测数据”，`dataSetId=4`，标识符 `CSTR:13452.11.1.01.001.2.00081.1`。官网登记所有者为国家海洋信息中心，完全公开/完全共享，按月更新，下载需登录。[官方数据集](https://mds.nmdis.org.cn/pages/dataViewDetail.html?dataSetId=4)
- 参考站：大陈，官方文件站码 **DCN**（不用文献中出现的DCH替代下载文件编码）；数据坐标为28.5°N、121.9°E，精度按原文件保留。这是参考站位置，**不是二号网箱实测部署坐标**。
- 已下载：2024-07至2025-08，共14个月、10,248条逐时观测，北京时间UTC+8。当前官方目录可见的最新文件为2025-08；不能称平台显示的是当前实时海况。
- 实测要素：风速、气温、水温各10,248个有效值；浪高9,957个有效值、291条缺测。水温9.0–30.8℃、浪高0.2–4.6m、风速0–20.4m/s。缺测值保留为空。
- 无流速、光照、盐度实测值可从本批文件提供时，页面显示“—”；不以仿真补实测。
- 留档：`data/china_stations/raw/DCN*.txt`原始字节与下载文件一致；对应JSON沿用现有官方v3定宽格式解析器。`DCN-source-manifest.json`记录官方文件标识、大小、SHA-256及下载日期，不包含登录凭据。

## 溶解氧、pH数据

来源为生态环境部国家海洋环境监测中心《海水水质监测信息公开系统》的已入库原始记录，**不是DCN站逐时传感器数据**。[官方水质系统](https://ep.nmemc.org.cn:8888/Water/)

按现有处理规则，以DCN参考站为中心，选择同属东海、60km内最近的最多40个点位，逐月聚合；本次得到42个有观测月份，范围2017-05至2026-07，月份不连续、不插值。点位距离参考站约3.0–52.3km，最近为TZ-DC02。原始记录和所有点位坐标/距离保留在`data/water_quality/DCN.json`及原始年度JSON。

这些值只作为附近海域的月度水质参考；点位距离是到参考站的距离，不是到网箱的距离。青岛XMD水质不再映射给site_03。月度类别出现并列众数时列出所有并列类别，不随机选一类；例如2020-10的一类/二类各5条。

## 页面与答辩口径

可以说：“二号网箱采用大陈外海养殖演示场景，水温与海况参考大陈海洋站历史观测，溶解氧和pH参考附近监测点月度数据。”

不能说：“我们获得了大陈深远海网箱的实时现场传感器数据”“本队网箱部署在该公开项目”“四个在用台站分属四个海区”。当前在用台站为ZFD/DCN/SSN/ZLG，覆盖渤海海峡、东海、南海三个海区；XMD数据保留为迁站前档案。

二号箱仍保留原许氏平鲉、库存、六角形几何、设备与阈值。历史高温超限如实显示；换观测海域不等于已论证当地养殖该鱼种的生产可行性。
